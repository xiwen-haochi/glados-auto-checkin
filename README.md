# GLaDOS 自动签到（Chrome 扩展）

在已登录 GLaDOS 的浏览器里，每天按设定时间自动签到。未上架商店，本地加载即可。

## 安装

1. 下载或克隆本仓库
2. 打开 `chrome://extensions`，开启右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录

## 使用

1. 点工具栏扩展图标，设置每天执行时间（默认 09:00），点「保存设置」
2. 点「立即签到」可马上执行一次，不用等定时
3. 结果会显示在弹窗里，底部可查看最近 20 条签到记录

选项：

- **启用每天定时签到**：关掉后只剩手动签到
- **前台标签页打开**：默认关闭；如果后台标签页签到失败（需要过验证码），再打开这个

## 注意

- 到点时浏览器要开着；如果关着，会在下次启动后补签一次（每天最多一次）
- 需要浏览器里已登录 glados.rocks，登录过期会提示

## 文件结构

```
manifest.json   扩展清单
background.js   定时与标签页调度
content.js      页面内点击签到、读取积分
popup.html/js   弹窗界面
icons/          图标
```
